WorkBuddy · 客户端接入

在你的 Windows 电脑上完成配置

下载工具，选择客户端，输入自己的 API Key。配置在你的电脑上完成，原文件会自动备份。

Windows 配置工具

支持 Windows 10 / 11（64 位），无需安装 Python，也无需管理员权限。

支持 Claude Code、Codex、OpenCode、DeepSeek Harness、Crush、ZCode。

下载 Windows EXE

下载后双击 WorkBuddy-Setup.exe，按窗口提示操作。请先安装你要使用的客户端。

发布记录与 SHA256 校验值

连接本网关

请使用你的电脑能访问的域名或 IP。API Key 请向网关管理员获取，并在下载的工具中输入。

三步完成接入

  1. 双击 EXE，选择客户端，然后选择“配置客户端”。配置 ZCode 前，请先退出 ZCode。
  2. 粘贴上面的网关地址，输入 API Key，选择默认模型并确认。
  3. 看到“配置成功”后，重新启动客户端即可使用。

需要恢复时，再次运行工具，选择对应客户端的“还原原始配置”。备份保存在当前用户的 .wb-agent-config 目录。
